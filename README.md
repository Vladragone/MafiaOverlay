# Mafia Tournament OBS

Локальная панель ведущего и прозрачный оверлей для трансляций спортивной мафии.

## Эфирные сцены

Кнопка «Создать 7 сцен» создаёт и настраивает в OBS:

- `STARTING SOON` — заставка с датой и обратным отсчётом;
- `STUDIO` — полноэкранная студийная камера с эфирным оформлением;
- `GAME` — игровая камера и панель десяти игроков;
- `NIGHT` — игровая камера, окно комментатора и панель игроков;
- `RESULTS` — полный протокол текущей игры из Mafia Unlimit;
- `STANDINGS` — текущая итоговая таблица турнира из Mafia Unlimit;
- `TECHNICAL PAUSE` — аварийная эфирная заставка.

В разделе «Данные для эфирных таблиц» укажите ID турнира и ID текущей игры. Таблицы получают данные через публичный API `https://mafiaunlimit.ru/api` и обновляются автоматически каждые 15 секунд.

Полноэкранные сцены используют единое черно-желтое оформление с координатной сеткой и тонкими эфирными акцентами. Игровые и студийные сцены сохраняют прозрачность, чтобы графика не перекрывала камеры.

На `RESULTS` и `STANDINGS` справа показываются лидер, его загруженный портрет и студийная веб-камера. Для `RESULTS` лидер определяется по максимальному баллу текущей игры, для `STANDINGS` — по первому месту итоговой таблицы. Источник камеры задается отдельно в настройках обеих сцен.

Кнопка «Настройка сцен» открывает редактор каждой сцены с предпросмотром. В нем можно изменить:

- заголовок, подпись, цвет фона и акцентный цвет;
- фоновое изображение;
- дату, время начала и отображение обратного отсчета;
- названия источников игровой и студийной камер в OBS;
- ссылку на игровой оверлей;
- ID турнира, ID текущей игры и интервал обновления таблиц.

Ссылки `RESULTS` и `STANDINGS` формируются автоматически по введенным ID. Перед созданием сцен в OBS сначала сохраните их настройки, чтобы источники были собраны с актуальными именами и адресами.

## Порядок работы

1. Создайте турнир: укажите название, этап и количество игр.
2. Заполните 12 участников (10 основных и 2 запасных) и добавьте от 1 до 3 судей.
3. Перед каждой игрой распределите десять участников по местам за столом.
4. Нажмите «Начать игру N». Все роли появятся в стартовом сером состоянии.
5. Нажмите «Показать оверлей», а затем назначайте роли в панели ведущего.
6. Кнопка «Скрыть оверлей» анимированно убирает оформление из эфира.

## Протокол игры

- «ЛХ» содержит три номера, названные первым убитым игроком.
- Дополнительный балл считается автоматически: три чёрных — `1.0`, два — `0.5`, иначе `0`.
- Для каждой ночи сохраняются отстрел, проверка дона и проверка шерифа.
- Для каждого дня сохраняется результат голосования.
- В каждом событии можно выбрать игрока, оставить поле незаполненным или указать `× Нет события`.
- Цвет номерной карточки и отметки дона/шерифа определяются текущей ролью игрока.

## Запуск

Самый простой способ в Windows — открыть `start.bat` двойным щелчком. Панель откроется в браузере автоматически.

Или через терминал:

```powershell
npm install
npm start
```

Панель управления: `http://localhost:4173`

Оверлей OBS: `http://localhost:4173/overlay.html`

Любую графическую сцену можно проверить отдельно:

```text
http://localhost:4173/scene.html?layout=starting
http://localhost:4173/scene.html?layout=studio
http://localhost:4173/scene.html?layout=game
http://localhost:4173/scene.html?layout=night
http://localhost:4173/scene.html?layout=results
http://localhost:4173/scene.html?layout=standings
http://localhost:4173/scene.html?layout=technical
```

## Добавление в OBS

1. В сцене нажмите `+` в списке источников и выберите «Браузер».
2. Укажите адрес `http://localhost:4173/overlay.html`.
3. Установите ширину `1920`, высоту `1080`.
4. Включите «Обновлять браузер, когда сцена становится активной».

## Управление сценами

В OBS откройте «Сервис → Настройки сервера WebSocket», включите сервер и запомните пароль. В панели нажмите «Подключить OBS» и укажите адрес `ws://127.0.0.1:4455`.

Состояние игры автоматически сохраняется в `data/state.json`. Аватары хранятся там же в виде данных изображения; рекомендуемый размер файла — до 2,5 МБ.

## Портреты игроков

Используйте PNG или WebP с прозрачным фоном, кадрированный примерно по грудь. Рекомендуемый размер — около `600 × 800` пикселей. В панели наведите курсор на фотографию игрока и нажмите «Загрузить PNG».

В начале игры роли серые. После назначения карточка анимированно обновляется в эфире: мирный получает красную подсветку, мафия — чёрную с буквой «М», дон — чёрную с «Д», шериф — красную с «Ш».
